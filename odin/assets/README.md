# Assets

- `m5x7.ttf`: the **m5x7** pixel font by Daniel Linssen (managore), https://managore.itch.io/m5x7. Creative Commons Zero v1.0 (free to use; attribution appreciated, and given on the About screen). It replaced a font taken from Windows XP's Small Fonts, which could not be shipped.

`tools/gen/gen_font.py` renders it (16 px, no anti-aliasing) into `odin/game/font_data.odin` and the VB oracle's `tools/vb-oracle/m5x7.json`.
