# Quirks of the original (VB.NET), to decide before or after porting

Found by reading `World.vb`, `NeutralDialog.vb`, `ShoppeDialog.vb`, `NeutralState.vb`. Not verified by running the game. All decided by the user on the port-planning pass; each entry ends with **Decision**.

1. **Auto-murder catch-up is unbounded.** `AutoMurder` loops `While now >= NextAutoMurder`, one attempt per interval. After a long absence (or a reloaded old save) it runs every missed attempt; with a halved-many-times interval the loop is huge. Port default: cap it (needed on wasm, a runaway loop freezes the tab). Decide the cap and whether capped time is forfeited. **Decision:** cap the attempts per catch-up (e.g. 1000), forfeit the rest, set next = now + interval.
2. **Catch-up only shows the last attempt.** Every attempt clears `Messages`, so after a catch-up only the final attempt's messages are visible; the earlier results still count. Port default: same. **Decision (with 4):** keep as original, last attempt's messages only.
3. **Auto-murder only runs on the neutral screen.** It is triggered inside `NeutralDialog.Description` (a getter with a side effect, evaluated every frame). While in the Shoppe nothing fires; on return it catches up. Port default: same observable result, but run it in the frame step; decide whether it should also tick in the Shoppe. **Decision:** tick from the frame step whenever a world is in play (neutral and Shoppe), not on the title/main menu.
4. **Auto-murder messages replace the player's.** An auto attempt clears and rewrites the message list, so a manual result can vanish within a second of showing. Port default: same. **Decision:** keep as original (see 2).
5. **Buying an auto-murder upgrade does not reschedule the timer.** The first buy starts the timer at now + interval. Later buys halve `AutoMurderInterval` but leave `NextAutoMurder` where it was; the new interval applies after the next firing. Port default: same. **Decision:** keep as original; no rescheduling on purchase.
6. **The cursor index survives screen changes.** `NeutralState` keeps one `currentChoice` for both dialogs. Pressing A on `Shoppe` (index 1) lands in the Shoppe with index 1, which is the first affordable upgrade (Cancel is index 0), so a second press buys it. It is reset to 0 only when it is out of range. Back in the neutral screen the cursor can sit on `Shoppe`. A DOM port with real buttons has no cursor; this quirk disappears with it. **Decision:** the cursor is remembered per screen (clamped when the list shrinks).
7. **Failing pays double.** Failure gives `difficulty x 2` XP; success gives `difficulty + old streak`. Failing is better than succeeding until the streak reaches the difficulty. May be deliberate (it is an idle-game economy); **do not "fix" without asking.** **Decision:** keep as original; deliberate economy.
8. **Message order on success:** `Success!`, `Streak bonus N XP!` (old streak, only if > 0), `New Record Success Streak!`, then `You get M XP`. The record line comes before the XP line it relates to. Port default: same. **Decision:** keep exact order and texts.
9. **Costs overflow.** Each purchase doubles its cost in a 32-bit `Integer`; VB throws `OverflowException` (unhandled, crashes) after ~21 skill buys, ~26 for difficulty. Other counters (XP, attempts, `100 * murders`) can overflow far later. Port default: use `i64` or cap. **Decision:** XP, costs, counters, skill and difficulty are `i64`, saturating at about 9e15 (never wrap); tests prove it.
10. **Unaffordable upgrades are described but not selectable.** The Shoppe text lists all three in red, but only affordable ones are choices. Port default: same. **Decision:** keep as original.
11. **`SuccessRate` truncates** (`100 * murders \ attempts`), shows `?` before the first attempt. **Decision:** keep truncated whole percent and `?`.
12. **Auto-murder timer is wall clock.** It uses `DateTimeOffset.Now` and is saved as an absolute time, so a save loaded later catches up (see 1). Changing the clock backwards stalls it. Port default: same with epoch ms. **Decision:** clamp: if next is more than one interval ahead of now (on load or tick), pull it to now + interval.
13. **Dead content.** Sfx constants for combat/crafting/eating, `CombatTheme`, `VictoryTheme`, `DeathTheme`, `EnemyHit.wav` etc., and `SPLORR.Game`'s maze/dice code are unused by this game. `aboot.txt` and `README.md` describe a different game. Port default: drop. **Decision:** drop all of it (audio is dropped too).
14. **Loading sets the world on the current dialog.** `WorldModel` keeps the world inside the current dialog object; abandon sets it to Nothing. Harmless today because the game menu is reachable only from the neutral screen. Port default: moot. **Decision:** moot.
